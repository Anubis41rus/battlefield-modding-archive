# Battle Royale для EVBots LAN

Патч содержит изменения Lua и React относительно [BF3BR/VU-BattleRoyale, f5212d7](https://github.com/BF3BR/VU-BattleRoyale/tree/f5212d7d82adb4ee9b3a9d28e52d5186ecc01cc8). В нём сохранены доработки запуска матча, лобби, парашюта, карты, инвентаря, зоны и аирдропа.

В чистой копии исходного мода переключитесь на `f5212d7d82adb4ee9b3a9d28e52d5186ecc01cc8` и выполните `git apply --check <путь-к-патчу>`, затем `git apply <путь-к-патчу>`.

Базовый мод принадлежит его авторам — KVN, Flash_Hit, breaknix, Janssent и kiwidog. Для запуска нужны Battlefield 3 с дополнениями, EVBots и зависимости из `mod.json`.
