## 1. Что сломано — по порядку важности

1. **★ Номера ботов клиент ≠ сервер (факт, прогон 230).** Клиент берёт `Player.id` из движка клиента, сервер мода — id
   нашего моста (`PlayerManager:CreatePlayer` → id). Не совпал ни один из 12 (MODLOG «Прогон 230»). Поэтому
   `ShootAtPlayer`/`ShootAtBot` от клиента уходят не тому боту — бот рядом не стреляет, пока по нему не выстрелишь.
   Как VU: один id на клиенте и сервере. Варианты: (а) id игроков у мода на сервере = id движка сервера (если движок
   реплицирует их клиенту — сверить по разбору `CLIENT-SLOTS`: `Player.id` = `+0x3EC`); (б) сервер шлёт клиенту
   соответствие имя → id по каналу (как список ботов `__ev_bots`, реестр В15). Предпочтительно (а). Реестр В19.
2. **Мышь в меню не работает в игре** (слова и скриншоты пользователя): меню и колесо видны, курсор виден, но наведения и
   кликов нет (в журнале нет ни одного события страницы от мыши). Гипотеза: BF3 держит мышь через DirectInput
   (исключительный режим) — Windows не шлёт окну мышиные сообщения. План: (1) проверить, двигается ли курсор; (2) при
   меню кормить WebView2 самим: позиция (`GetCursorPos`) и кнопки (`GetAsyncKeyState`) по таймеру → `SendMouseInput`;
   (3) если курсор стоит — разобрать `DirectInput8Create` игры (импорт zbf3) и при меню отпускать мышь (`Unacquire`) или
   подменять `GetDeviceState/GetDeviceData`. Без игры (`client-harness`) это не ловится — там обычные сообщения.
3. **Меню в полноэкранном режиме не видно.** Решение пользователя 25.10: **как VU — рисовать меню в кадре игры.**
   План (составить и согласовать в начале сессии): перехват `IDXGISwapChain::Present` игры (d3d11, импорт zbf3), кадр
   WebView2 → текстура D3D11 (Windows.Graphics.Capture от визуала DirectComposition или своя копия) → рисование
   прямоугольником поверх кадра игры перед Present; ввод — как в п. 2. Риски: стабильность (Present — горячий путь),
   полноэкранный эксклюзивный + DComp. Кандидат — отдельный модуль в `ev-core.dll` (у VU рендер Gameface — в vu-core).
4. ~~Колесо Alt мигает в игре~~ — **снято:** пользователь 25.10 после прогона 230: «сейчас нет мигания Alt» (в журнале
   17:15:48–52 «ввод — меню/игре» — гипотеза: повторные нажатия). Без игры тоже не мигает (с 229).
