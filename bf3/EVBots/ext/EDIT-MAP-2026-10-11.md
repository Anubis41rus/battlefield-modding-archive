## A8. Мост сделан ОПЦИОНАЛЬНЫМ (после регресса 19:51)
`RegisterVextPlayerManager` теперь регистрирует `NativeBridge` **только** при
`LEGACYEXT_BRIDGE=1`. По умолчанию моста нет, `NativeBridge` = nil, а Lua-ветки
пропускаются по `if NativeBridge ~= nil then` — то есть DLL ведёт себя ровно
как до появления моста.

Причина: регресс воспроизводился только с мостом, и без возможности его
выключить нельзя было отделять собственные правки от поведения модов.

**Проверка значения, а не факта существования:**
```cpp
char b[8] = {};
const DWORD bn = ::GetEnvironmentVariableA("LEGACYEXT_BRIDGE", b, sizeof(b));
bridgeOn = (bn == 1 && b[0] == '1');
```
`GetEnvironmentVariableA(name, nullptr, 0) == 0` означает «переменная НЕ
задана», а не «переменная равна нулю» — на этом уже обжигались дважды
(см. A7 и `LEGACYEXT_SPM_PROBE`, где 0 = «выключено», а 1 = «включено»).
Для `*_PROBE` и `*_SPAWN` значение `0` означает ВЫКЛЮЧЕНО (там проверка `> 0`),
для `LEGACYEXT_BRIDGE` значение `1` означает ВКЛЮЧЕНО. Не путать.
