## 4. План (по шагам, каждый — сборка, тест-хост, прогон)

1. **Убрать серверные обходы** (раздел 3): у каждого игрока теперь наш клиент — как у VU, считает клиент. Флаг отката
   `EVBOTS_SERVER_CLIENT_EMU=1`. Вопрос: друзья без нового клиента останутся без лучей ботов — у VU так же (без клиента
   мода не играют).
2. **Интерфейс ev-core → EVBots** (как `GetModdingInterface` у VU, только наоборот — хост даёт сервисы): экспорт
   перехвата (`EvHookInstall/Remove`), подписка на кадр клиента и тик сервера, консоль, канал. `EVBots.dll` перестаёт
   ставить перехваты сам.
3. **Перенос механизма** `InlineHook`/`X86Length` в `ev-core.dll`; `EVBots.dll` зовёт его через экспорт.
4. **Перенос клиентских хуков** (кадр, PushScreen, Present, курсор/Raw Input) в `ev-core.dll` — то, что записано в
   `ev-core\README.md` с 23.10.
5. **Перенос серверных хуков** (тик, сообщения, урон, отряды, статистика, CombatArea, EntityFactory, RCON) — по одному,
   с прогоном.
6. `lua.dll` — без изменений.

Риски: перенос трогает горячий путь (тик/кадр); делать по одному хуку, со сверкой байтов (правило 18) и прогоном после
каждого шага. Друг — полный комплект (все три DLL), не одна.
