# GOAL — что именно мы делаем (зафиксировано 08.10.2026, уточнено в тот же день)

Подробный разбор: `VU-HOWITWORKS.md` и `DESIGN-LOCAL.md`. План работ: `..\PLAN.md`.

## Задача

**Legacy** — свой локальный аналог **Venice Unleashed**, чтобы играть с
друзьями в **LAN-пати с ботами**, **полностью без интернета**, и чтобы работали
**Lua-моды уровня VU** (а не только нативные боты).

Это повторение VU по смыслу: та же архитектура, та же совместимость модов,
тот же удобный запуск — но вместо облака VU у нас **свой бэкенд «Legacy»**.

## Что НЕ является целью

- **`botlayer.dll` — не продукт.** Это прошлая попытка сделать нативных ботов.
  Их ИИ (brain.ini, 252 параметра) слабее VU-ботов, они не умеют ездить, режимов
  и функций мало. Мы **не развиваем** его ИИ и **не переносим** brain.ini.
- Мы **не модифицируем VU**, **не модифицируем BF3** и **не трогаем ВУ-мод fun-bots** ни кодом, ни `Config.lua`, ни данными: из мода берём только информацию. Пишем своё.
- Отступление (17.10): в живом моде `Config.lua` — `InitNumberOfBots = 15` вместо оригинальных 10. Код не тронут; оригинал в `backup\2026-10-17\fun-bots-check\`. Откат меняет число ботов на стенде, решение — отдельно (см. MODLOG 17.10).
- Не повторяем: Zeus-облако, TLS/`cacert.pem`, asmjit, CoHTML/V8 WebUI (пока),
  раздачу обновлений, `server.key` как понятие, `-env prod|dev`.

## Архитектура (4 слоя, как у VU)

| Слой | У VU | У нас | Готовность |
|---|---|---|---|
| Лаунчер (клиент+сервер в одном бинаре) | `vu.exe` / `vu.com` | **`Legacy.exe`** (свой) | строим (фаза 3) |
| Бэкенд = Zeus | Zeus, облако | **«Legacy»** — наш бэкенд | **~75% готово** (фаза 2) |
| Мод-система в игре | `veniceext.dll` (Lua 5.4 + SOL3) | **`legacyext.dll`** | строим (фаза 4) |
| Моды | VU-моды, раздаются с сервера | те же VU-моды | `fun-bots` есть (фаза 5) |

Плюс: **инъекция** — у нас уже работает (`activation-loader --dll`);
**прогресс/профили/статистика** — уже работают (`profiles\`, `progress\`);
**навигация — отдельной задачи нет:** навмеш вшит в уровень
  (`PathfindingBlob`), Lua-боты берут его из движка.

## Продукт

### Критерий успеха №1
`BF-Portable\Battlefield_3_Server\Instance\Admin\Mods\fun-bots\` (с 16.10; раньше была копия в `LegacyBF3\mods`, теперь в trash) — готовые VU-боты (Joe91, 328★, 114 `.lua`:
`BotSpawner` 75 КБ, `GameDirector` 71 КБ, `BotMovement` 42 КБ, `BotManager` 50 КБ) —
**запускается на Legacy как мод, без единой правки логики.** Интеллект приходит
из Lua, а не из нативного слоя. Мод объявлен как
`"HasVeniceEXT": true, "Dependencies": {"veniceext": ">=1.12.0"}`.

### Критерий успеха №2
**LAN-пати:** гость открывает `Legacy.exe`, видит сервер в списке, входит
в один клик, играет с ботами. У ботов **виден ранг/уровень**.

### Критерий успеха №3
Моды, написанные для VU, работают: структура `mod.json` +
`ext/{client,server,shared}/__init__.lua`, свой `require` с префиксом
`__shared/`, окружение Lua 5.4.2 с вырезанными `dofile/load/loadfile/os.execute`
и добавленными `string.starts/ends`, `json.encode/decode`.

## ★ Ключевое упрощение: обновлений не будет

Ни BF3, ни VU больше не обновляются. Значит:

- **Жёстко зашитые адреса — норма.** AOB ради устойчивости к патчу НЕ делаем.
  Адреса из `HOOK-TABLE.md` берём как есть (8 из 8 совпали байт-в-байт).
- Не нужны проверки версий, фоллбэки, «патч сломал хук» — их просто не будет.
- `server.key` заменяется своим идентификатором сервера.
- Интернет не требуется нигде: ни обновлений, ни TLS, ни Zeus.
- Среда детерминирована и зафиксирована намертво — это сильно упрощает
  инженерию.

## Проверка, что «интернет не нужен»

| Что | Интернет? |
|---|---|
| Клиент BF3 → наш редиректор | нет, LAN |
| Blaze-сессия | нет, LAN |
| Аккаунты/солдаты/прогресс | локально: `profiles\`, `progress\` |
| `server.key` | не используем, свой GUID |
| Lua-моды | лежат локально в `Admin\Mods\`, раздаются по LAN |
| Обновления VU | не нужны |
| WebUI | не делаем первым |
| Заглушка EA-сервисов | локальная (`sinkhole`) |

**Интернет не нужен нигде.**

## Порядок сборки

1. **Фаза 2** — «Legacy» = Zeus: свой ID сервера, `GET /servers`, автодетект
   LAN-IP, вход по `legacy://join/<id>`, раздача модов, инстанс-каталог в
   структуре VU (`Admin\Startup.txt`, `MapList.txt`, `ModList.txt`, `Mods\`).
2. **Фаза 3** — `Legacy.exe`: один бинарь клиент+сервер, вкладка «Серверы»,
   профили/аккаунты, создание сервера в окне с выводом.
3. **Фаза 4** — `legacyext.dll`: экспорт + Lua 5.4.2 + окружение VEXT +
   свой `require` + загрузчик модов + таблица нативов + SOL3 + первый хук
   `0x0117EA40` + `PlayerManager`.
4. **Фаза 5** — `fun-bots` без правок + **ранг ботов** (persona + `progress.json`)
   + ранг ботов (persona + `progress.json`).
5. **Фаза 6** — доказательства (видео/скриншоты), `um publish check`, field note.
