# EV Launcher (бывший LegacyFriend) — лаунчер «BF3 с ботами»

> 20.10.2026: exe — `EV Launcher.exe`, ставится установщиком в `<папка с играми>\EVBots\` (файлы из payload лаунчер больше не
> копирует). Новое: тикеты/очки по режимам (+ время CTF; `MainWindowRules.cs`, RCON — `RconRules.cs`), иконка и логотип, md5 сборки
> в «Проверить файлы», поиск сервера без обхода диска, папка сервера `BF-Portable` или `Battlefield Portable`. Ниже — прежнее
> описание экранов (имена в тексте — старые).

Свой GUI из `Legacy\launcher` (C#, .NET 10 WPF). Два экрана:

1. **Шаг 1 — вход или регистрация.**
   - «Сервер»: список серверов в сети находит сам (LAN-объявления, UDP 47990). «Этот ПК» = я хост. IP вручную — только если друга нет в списке.
   - Логин (3..32), пароль (от 4), ник. Кнопки «Войти» (`POST /accounts/login`) и «Регистрация» (`POST /accounts/ensure` на бэкенде по указанному IP). Хост при входе сам поднимает бэкенд.
   - «Проверить файлы» — пишет в лог, что найдено: `[OK]` или `[НЕТ]` и что положить и куда (игра, сервер, мод, стенд Legacy, активация, бэкенд, .NET 10, фаервол). «Указать папку Legacy…» — если стенд называется не `BF3LegacyLan`.
2. **Шаг 2 — после входа.**
   - Хосту — «Мой сервер»: карта, режим, боты, «Поднять сервер» (бэкенд + сервер через evbots-loader), «Остановить».
  - «Фаервол (UAC)» — на экране входа, один раз на каждом ПК (хосту и гостю): URL-ACL на HTTP бэкенда по LAN-адресу, порты, разрешение bf3.exe и сервера. Без URL-ACL бэкенд слушает только 127.0.0.1, и гость не войдёт. После нажатия хост перезапускает сервер: HTTP-адрес берётся при старте бэкенда.
   - Обоим — «Войти в игру»: список серверов с IP входа, запуск клиента BF3 через evbots-loader с `personaref` (гость играет под своим солдатом).
   - «Сменить пользователя» — назад на Шаг 1.

Стили тёмные, обводки полей видимые, фокус подсвечен акцентом. Лог внизу виден на обоих экранах.

## Файлы кода

`MainWindow.xaml` (экраны; стили в `App.xaml`), `MainWindow1.cs` (старт, карты), `MainWindowAuth.cs` (вход), `MainWindow2.cs` (тик, список), `MainWindow3.cs` (хост), `MainWindow4.cs` (вход в игру, фаервол), `MainWindowLan.cs` (LAN-список), `MainWindowCheck.cs` + `FileCheck.cs` (проверка файлов), `PathFinder.cs` (поиск стенда), `Installer.cs` (payload), `FriendSettings.cs`.

## Сборка

```powershell
dotnet build src\LegacyFriend\LegacyFriend.csproj -c Release
```

## Установка для друга

- `C:\Games\dist\LegacyFriend-Setup.exe` — окно установки без консоли: ищет папку с Battlefield 3, ставит `LegacyFriend\` рядом с ней и создаёт ярлык «Legacy BF3». Исходник установщика — `Legacy\launcher\src\LegacySetup\`.
- Запасной вариант — `install.cmd` из архива `dist\LegacyFriend-kit-2026-10-19.zip`.
- Живая установка на машине пользователя — `C:\Games\LegacyFriend\`; это не исходник, его не путать с этим каталогом.

## Что нужно на машине

- Рядом `BF3\` (bf3.exe) и `BF-Portable\` (bf3_server_Final.exe) — лаунчер сам установит payload при первом запуске (бэкапы в `stand\backup\`).
- Хост и гость: .NET 10 Runtime (бэкенд) и один раз «Фаервол (UAC)» на каждом ПК.
- Гость: только BF3 + evbots-loader из комплекта (в старой установке — activation-loader); аккаунт живёт на бэкенде хоста.
