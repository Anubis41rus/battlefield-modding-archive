- `FUN_105363a0` (`vu_mode.txt`): правит код bf3.exe — непосредственные значения (0x005E871B = 2·частота, 0x005F2458 /
  0x00A3031B = частота, 0x01084220 — байт), адреса констант в инструкциях (30.0f → своя частота, 30.0 double, 0.1333f → 1/частота,
  0.1 → 0.1·k, 0.01 → 0.01/k), константы данных (0x02080B80 1/частота double, 0x021ACAC0 0.04/k, 0x02082C9C и 0x021AD55C

  частота аргументом), 0x0118D060 таймер с фиксированным шагом, 0x00FB46D0 соединение и 0x00A53A20 сетевой объект (частота,
  10/15·k, полоса 32000·k), 0x005BB1F0 шаг времени (60: 1/60 → 1/45; 120: 1/120 → 1/60); поправки физики **при 60 и 120**
