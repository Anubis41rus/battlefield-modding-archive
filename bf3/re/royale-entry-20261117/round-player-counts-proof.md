# Нулевые значения roundStartPlayerCount / roundRestartPlayerCount

17.11.2026. Изолированный `RoundPlayerCounts.cpp/.h`, без изменений Royale и без запуска стенда агентом.

## Причина

Серверный обработчик Start `0113FD60` отвергает 0 веткой `0113FE0F`. Затем ranked-ветка `0113FE81` ограничивает число снизу 4. Restart `01140010` принимает 0, но ranked-ветка `011400E6` ограничивает его снизу 3. Поэтому журнал F818D265 показывал InvalidValue и OK 3.

VU регистрирует собственные обработчики Start `101E3560` и Restart `101E31D0`. Они сохраняют запрошенные значения в ServerSettings+3C (`101E3785/88`) и +40 (`101E33F5..3412`), без ranked clamp. Число проверяется `100B09A0`, разбор integer выполняют `1018A810` и `101D96A0`.

## Патч

| Адрес сервера | Было | Стало | Назначение |
| --- | --- | --- | --- |
| 0113FE0F | 75 51 | EB 51 | Принять 0 |
| 0113FE81 | 74 1E | EB 1E | Сохранить Start без ranked clamp |
| 011400E6 | 74 1E | EB 1E | Сохранить Restart без ranked clamp |

Сохраняются штатные parser, -1/default, запись настроек, ответ RCON и effective getters. Это совместимость данных RCON, а не полная подмена VU RCON.

VU original getter `0089A9C0` сохраняет minimum 1 (`0089AA7A`), как серверный `012D7620` (`012D76BC`). VU detours `101CCF10` / `101CCEF0` возвращают 0 только при отдельном `vu.DisablePreRound` (флаг `108CDB8A`, запись `101E822A`). Royale эту команду не вызывает: его `DisablePreRound()` вручную отправляет StartRound / Disable / RoundStarted. Поэтому effective getter намеренно остаётся прежним, принудительное выключение PreRound не добавляется.

## Защиты и интеграция

`InstallRoundPlayerCountCompatibility()` вызывать только на dedicated server, до первого LoadResources/RCON. Проверяется имя и base сервера, шесть полных контекстов инструкций/записей, три места патчей. Все проверки выполняются до первой записи. Несовпадение блокирует весь пакет. Ошибка записи откатывает ранее записанные места и логируется; повторные попытки после ошибки запрещены. Каждое место логируется. `EVBOTS_ROUND_PLAYER_COUNTS=0` выключает пакет. DLL-owned callbacks отсутствуют: новые переходы ведут только в оригинальный exe.
