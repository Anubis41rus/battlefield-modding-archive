# Royale, результаты клиентских лучей 17.11.2026

В последнем клиентском логе 461 отказ SpatialRaycast из CommonSpatialRaycast.lua:59 и 416 отказов Raycast из GunshipClient.lua:71. Старый Raycast выдавал ошибку после успешного нативного попадания, если не получался weak handle для rigidBody. В локальной VU Docs это поле допускает nil. Gunship проверяет наличие попадания, а пинги и эффекты используют его координаты.

SpatialRaycast прекращал копировать результаты после первого отказа weak handle. Сообщение старого прогона не определяет, был ли отказ в запросе, коллекторе или lifetime. В новой версии живые Entity передаются в исходном порядке, неподтверждённый элемент пропускается, ошибки запроса и коллектора различимы. Из результата Raycast позиция, нормаль, материал, часть и кость передаются при отсутствующем rigidBody. Оба пути подтверждают отражаемый Entity до захвата weak token. Lua получает только generation-checked evbots.BlueprintEntity.

Проверено по локальному zbf3.exe SHA256 8201C5E14667D511F402C424D5C87A3A5ED2D9FDF81C67C914A145A9D3BC42B9. ClientStaticModelEntity vtable0214A748 начинается с 010AC9F0 (B8 B4 B5 3E 02 C3, TypeInfo023EB5B4), ClientSoldierEntity vtable0214BD40 с 010C2A80 (B8 B8 BA 3E 02 C3, TypeInfo023EBAB8). Рефлексия проверяется считыванием такого getter и цепочки типа. Штатный BR создаёт StaticModelEntity для оружия (WeaponSkeletonMeshModel.lua:31,51–55), сохраняет instanceId (BRLootPickup.lua:128), ищет им же по результату SpatialRaycast (BRLooting.lua:111–116). EVBots выдаёт в обоих местах instanceId одного и того же native Entity. Результат луча по реальному предмету надо подтвердить на клиенте.

Сборка изменённого файла MSVC x86 /W4 /WX и 31 проверка изолированным Lua-хостом прошли. Смешанный список с неподтверждёнными элементами сохраняет обе живые сущности и их порядок. При отказе weak остаётся физическое попадание со всеми обязательными полями. Проверены прежние ошибки входных параметров и запрет вызова вне кадра игры. Запуск теста в test-client-query-results.cmd, вывод client-query-results-test.log. Бэкап исходника в C:/Games/backup/2026-11-17/royale-round-fixes/VextClientRaycast-build-next-pre.cpp.
