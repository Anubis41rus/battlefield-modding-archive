# Battlefield Modding Archive

Архив наработок по Battlefield 3, сохранённых перед переходом на Battlefield 4.

- [EVBots](bf3/EVBots) — исходники LAN-бэкенда, лаунчера, загрузчика и реализации Lua API. Состояние стенда и результаты проверок записаны в [передаче Royale](bf3/EVBots/stand/ROYALE-HANDOFF-2026-11-17.md).
- [Battle Royale](bf3/royale) — изменения Lua и интерфейса для EVBots Royale LAN.
- [Исследования](bf3/re) — отчёты о работе движка и VU, включая [индекс 15 чанков](bf3/re/vu/veniceext.chunks.txt).
- [universal-modder](universal-modder) — снимок инструментария с локальными правками и базой знаний. Лицензия и авторство указаны в [LICENSE](universal-modder/LICENSE).

Для сборки установщика нужны локальные ресурсы BF3 и `kit.zip`. Установщик, образ игры, бинарные чанки VU и полные выгрузки декомпилятора хранятся отдельно. В копии исходников для GitHub пароль RCON заменён на значение для примера. Перед запуском сервера задайте свои настройки RCON.
